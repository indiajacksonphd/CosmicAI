# Supervised Machine Learning for Astronomy — NRAO CosmicAI

Teaching materials developed for the **June 2026 CosmicAI program** at the **National Radio Astronomy Observatory (NRAO)**.

This project introduces supervised machine learning through mathematical foundations, Python programming, and hands-on analysis of heliophysics data. Activities connect the underlying mathematics to Jupyter notebook implementations and interpretation of model results.

## Topics

- **Linear regression:** Least-squares fitting, model implementation, and evaluation using scientific time-series data.
- **K-nearest neighbors (KNN):** Euclidean distance, feature-based classification, and confusion matrices.
- **Scientific applications:** Examples involving ACE/EPAM measurements and solar-flare imagery.

## Computational Environment

Course activities used **[Helio-Lite](https://github.com/indiajacksonphd/Helio-Lite)**, a browser-based, JupyterHub scientific computing environment, to support reproducible, hands-on exercises.

The notebooks use Python and common scientific computing libraries, including NumPy, pandas, Matplotlib, and scikit-learn. Open the relevant notebook in JupyterLab and follow its instructions; dataset access and any additional dependencies are described in the individual exercises.
